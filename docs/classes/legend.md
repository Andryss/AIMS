# Легенда представления прецедента

## Стереотипы

| Обозначение | Значение |
| --- | --- |
| `actor` | Внешний пользователь или система |
| `boundary` | Граница взаимодействия с системой |
| `control` | Сервис, координирующий сценарий |
| `entity` | Данные предметной области |
| `request` | Данные запроса к API |
| `response` | Данные ответа API |
| `React component` | React-компонент |
| `TypeScript module` | Модуль TypeScript |
| `OpenAPI DTO` | Модель сгенерированного API |
| `JPA entity` | Сущность хранения JPA |
| `Spring Data` | Репозиторий Spring Data |

## Связи

| Обозначение | Название | Значение |
| --- | --- | --- |
| `-->` | Направленная ассоциация | Исходный элемент инициирует взаимодействие с целевым |
| `..>` | Зависимость | Исходный элемент использует целевой |
| `..\|>` | Реализация | Класс реализует интерфейс |
| `*--` | Композиция | Часть принадлежит целому и не существует отдельно |
| `o--` | Агрегация | Целое объединяет независимо существующие части |
| `--` | Ассоциация | Элементы структурно связаны без направления |
