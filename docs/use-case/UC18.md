# UC18. Обработка заявки на тюремное заключение

## 1.Use-Case Name (Название прецедента)

UC18. Обработка заявки на тюремное заключение.

Связанные требования: 3.1.5.2.

## 2.Actors (Акторы)

Основное действующее лицо: Тюремный надзиратель.

## 2. Brief Description (Краткое описание)

Тюремный надзиратель получает заявку на тюремное заключение, принимает ее в обработку, уточняет данные и фиксирует
результаты рассмотрения. В ходе содержания субъекта надзиратель отражает изменения в его заключении.
